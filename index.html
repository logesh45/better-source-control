SOURCE CONTROL FOR
AGENTS WORKING IN PARALLEL.

More agents should mean
more progress.
Not more repeated work.

01 / BEFORE THE FIRST EDIT

Don’t solve it twice.

Ask about a task, file, or symbol. Find who worked on it, inspect their checkpoint, and decide what to reuse before another agent starts over.

02 / WHILE AGENTS WORK

Separate work. Shared awareness.

Give each agent a session with clear intent and claims. Work in isolated workspaces, capture progress in checkpoints, and surface overlapping claims before integration.

03 / WHEN THE WORK IS READY

Bring the work together.

Check whether the sessions can compose. Propose a release from their checkpoints, then accept a shared frontier with the originating sessions still attached.

ADOPT BETTER. KEEP YOUR CODE.

Start with Git.
Work with Better.
Export when ready.

No clean slate required. Import your current Git snapshot, let agents collaborate through Better sessions and checkpoints, and export a Git patch when your team is ready to publish the result.

$ better import git

# After agents checkpoint their tested work:
$ better compose
$ better release propose --message "ready"
$ better release accept <release-id> --by human:owner

$ better export git frontier --patch /tmp/frontier.patch
